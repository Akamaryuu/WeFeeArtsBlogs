# 自己紹介

**木内 和也（赤魔龍）｜WeFeeArts**

フリーランスのフルスタックエンジニア（サーバーエンジニア）であり、職業訓練・新人研修のIT講師。
職業訓練指導員（情報）の資格を持ち、IT業界歴は2011年から。
現場の「今」を、一生モノの「絆」へ。

> 「論理を磨き、情熱を絶やさず、一生モノの『絆』を。」

## 仕事 — 開発と講師、二つの「季節」

現役SEとして開発に専念する「開発シーズン」と、講師として教育に注ぐ「講師シーズン」を行き来しています。

- 大学ではロボティクスを専攻し、東京のベンチャーで0からシステムを立ち上げたのが原点
- エンジニア30名以上のマネジメントや、SES企業での採用担当も経験
- 新人研修は多数の企業で担当し、最大で100名を超えるクラスも。職業訓練の講師歴も長く、「市場から逆算するカリキュラム設計」を軸に人材育成をしています
- 技術の現在地: Java / PHP / Python / JavaScript・TypeScript、C#、Oracle / MySQL / PostgreSQL、AWS、Docker、Linux（RHEL / Ubuntu）。現役SEとして大手のサーバー構築（RHEL9、シェルスクリプト）にも参画中
- 教え方: 「面倒見がいい」とよく言われます。分からない質問でも、相手の知りたいことを一緒に掘り下げて理解するのが持ち味です

現場を知らない講師にはなりたくないので、「現役」であることにこだわっています。

## WeFeeArts — 20年続くギルド

WeFeeArts（うぃふぃあーつ）は、約20年前の2006年頃に私が結成したMMORPGのギルドです。

- メイプルストーリー → トリックスター → ラテールと韓国産MMORPGを渡り歩いた時代に誕生
- PSO2 では Ship07 のチーム「WeFeeArts」でチームマスター
- Minecraft ではMODサーバーを立て、建築と運営を担当
- 週末は子供向けスクールやイベントで「創る楽しさ」を伝える活動も

技術は数年で古くなりますが、ギルドで築いた「絆」は20年経っても色褪せません。今は個人ブランドとして、この名前で活動しています。
